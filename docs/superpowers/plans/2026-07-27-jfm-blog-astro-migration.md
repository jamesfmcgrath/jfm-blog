# jamesfmcgrath.org Astro Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild jamesfmcgrath.org as a static Astro site styled per the `Blog.dc.html` mockup, migrate the 33 real posts plus one standalone page from the WordPress export, and prepare (but do not run) a Hostinger deploy workflow.

**Architecture:** An Astro 6 project mirroring the structure and conventions already established in the sibling project `muirriasc` (content collections loaded via `glob()`, per-component scoped `<style>` blocks plus one global stylesheet, self-hosted fonts via `astro:assets` `Font`). Two content collections — `blog` (33 posts) and `pages` (1 page) — both rendered through a single flat catch-all route so every post keeps its exact pre-existing WordPress URL. Content migration runs as a one-time local script, not part of the build.

**Tech Stack:** Astro 6.2.2, `@astrojs/mdx` 5.0.4, `@astrojs/rss` 4.0.18, `@astrojs/sitemap` 3.7.2, `sharp` 0.33.5, Node >=22.12.0. Migration tooling: `wordpress-export-to-markdown` 3.0.6, `xml2js` (for a pre-filter script). Accessibility check: `playwright` 1.62.0 + `@axe-core/playwright` 4.12.1.

## Global Constraints

- Node engine: `>=22.12.0` (`.nvmrc` pinned to `v22.22.2`, matching `muirriasc`).
- Astro fonts self-hosted via `fontProviders.google()` — no Google Fonts CDN request at runtime (confirmed available in installed Astro 6.2.2 at `node_modules/astro/dist/assets/fonts/providers/index.js`).
- Posts live at flat `/{slug}/` (root level), matching every existing WordPress post permalink exactly. The archive stays at `/blog/`. No redirect is needed for posts.
- Design tokens (hex values, fonts, spacing) come from `Blog.dc.html` and must not drift from the approved spec at `docs/superpowers/specs/2026-07-27-jfm-blog-astro-migration-design.md`.
- Semantic HTML, full heading hierarchy, visible focus states on every interactive element, skip-to-content link — carried over from the mockup as real behaviour, not decoration.
- WCAG 2.1 AA minimum; zero `@axe-core/playwright` violations on all four page templates before any page is considered done.
- Only 33 `post` items + 1 `page` item (`learn-javascript-for-beginners`, `wp:post_id` 1039) from the WordPress export are real content. Everything else (48 `attachment`, 124 `wpa-stats`, 6 other `page` items, `wp_global_styles`/`wp_navigation`/`wp_template*`) is excluded.
- **No `gh secret set` and no workflow run/deploy of any kind happens without the user's explicit go-ahead at that specific moment** — this plan only creates the workflow file.
- The `DEPLOY_PATH` guard in the deploy workflow must reject anything whose domain segment is not exactly `jamesfmcgrath.org` (not just "shaped like" a Hostinger path) — this is stricter than `muirriasc`'s existing guard and is the direct ask from the incident described in the spec.

- [ ] **Step 3: Write `src/lib/excerpt.ts`**

```ts
export function deriveExcerpt(body: string, max = 200): string {
	const plain = body
		.replace(/^#{1,6}\s+/gm, '')
		.replace(/`{1,3}[^`]*`{1,3}/g, '')
		.replace(/\[([^\]]+)\]\([^)]+\)/g, '$1')
		.replace(/[*_]{1,3}([^*_]+)[*_]{1,3}/g, '$1')
		.replace(/\s+/g, ' ')
		.trim();

	if (plain.length <= max) {
		return plain;
	}

	const truncated = plain.slice(0, max);
	const lastSpace = truncated.lastIndexOf(' ');
	return truncated.slice(0, lastSpace > 0 ? lastSpace : max) + '…';
}
```

- [ ] **Step 3: Write `scripts/migrate-wordpress/filter-export.mjs`**

```js
import { readFile, writeFile } from 'node:fs/promises';
import xml2js from 'xml2js';

const KEEP_PAGE_POST_ID = '1039';

export async function filterExport(xmlString) {
	const parsed = await xml2js.parseStringPromise(xmlString);
	const channel = parsed.rss.channel[0];
	const items = channel.item ?? [];

	channel.item = items.filter((item) => {
		const postType = item['wp:post_type']?.[0];
		const postId = item['wp:post_id']?.[0];

		if (postType === 'post') return true;
		if (postType === 'attachment') return true;
		if (postType === 'page' && postId === KEEP_PAGE_POST_ID) return true;
		return false;
	});

	const builder = new xml2js.Builder();
	return builder.buildObject(parsed);
}

async function main() {
	const [, , inputPath, outputPath] = process.argv;
	if (!inputPath || !outputPath) {
		console.error('Usage: node filter-export.mjs <input.xml> <output.xml>');
		process.exit(1);
	}

	const xml = await readFile(inputPath, 'utf8');
	const filtered = await filterExport(xml);
	await writeFile(outputPath, filtered, 'utf8');
	console.log(`Wrote filtered export to ${outputPath}`);
}

if (import.meta.url === `file://${process.argv[1]}`) {
	await main();
}
```

```js
import { readFile, writeFile } from 'node:fs/promises';
import xml2js from 'xml2js';

export async function buildRedirects(xmlString) {
	const parsed = await xml2js.parseStringPromise(xmlString);
	const items = parsed.rss.channel[0].item ?? [];

	const lines = items
		.filter((item) => item['wp:post_type']?.[0] === 'attachment')
		.map((item) => {
			const link = item.link?.[0];
			const path = new URL(link).pathname;
			return `RedirectMatch 301 ^${path}$ /`;
		});

	return [
		'# Generated by scripts/migrate-wordpress/build-redirects.mjs',
		'# Old WordPress attachment permalinks, which have no equivalent page on the new site.',
		...lines,
		'',
	].join('\n');
}

async function main() {
	const [, , inputPath, outputPath] = process.argv;
	if (!inputPath || !outputPath) {
		console.error('Usage: node build-redirects.mjs <input.xml> <output .htaccess>');
		process.exit(1);
	}

	const xml = await readFile(inputPath, 'utf8');
```

### Task 10: Accessibility verification

**Files:**
- Create: `scripts/a11y-check.mjs`

**Interfaces:**
- Consumes: the built `dist/` output (via `astro preview`), `@axe-core/playwright` (Task 1 devDependency).
- Produces: a script exiting non-zero if any of the four page templates has an axe violation, in either theme.

- [ ] **Step 1: Install the Playwright browser** (one-time local setup, not part of the automated script)

Run: `npx playwright install chromium --with-deps`
Expected: exits 0.

- [ ] **Step 2: Write `scripts/a11y-check.mjs`**

```js
import { chromium } from 'playwright';
import AxeBuilder from '@axe-core/playwright';
import { preview } from 'astro';

const PATHS_TO_CHECK = ['/', '/blog/', '/right-sizing-government-websites/', '/learn-javascript-for-beginners/'];

async function checkPage(page, path, theme) {
	await page.goto(`http://localhost:4321${path}`);
	await page.evaluate((t) => {
		document.documentElement.dataset.theme = t;
	}, theme);
	const results = await new AxeBuilder({ page })
		.withTags(['wcag2a', 'wcag2aa', 'wcag21a', 'wcag21aa'])
		.analyze();

	if (results.violations.length > 0) {
		console.error(`\n${path} (${theme} mode): ${results.violations.length} violation(s)`);
		for (const violation of results.violations) {
			console.error(`  - [${violation.impact}] ${violation.id}: ${violation.help} (${violation.nodes.length} node(s))`);
		}
	} else {
		console.log(`${path} (${theme} mode): OK`);
	}

	return results.violations.length;
}

async function main() {
	const previewServer = await preview({ root: process.cwd() });
	const browser = await chromium.launch();
	const page = await browser.newPage();

	let totalViolations = 0;
	for (const path of PATHS_TO_CHECK) {
		for (const theme of ['light', 'dark']) {
			totalViolations += await checkPage(page, path, theme);
		}
	}

	await browser.close();
	await previewServer.stop();

	if (totalViolations > 0) {
		console.error(`\n${totalViolations} total violation(s) found.`);
		process.exit(1);
	}
	console.log('\nAll pages pass with zero violations in both themes.');
}

main();
```

Note: `/right-sizing-government-websites/` is used as the representative post-page check — replace with whichever real post slug you want covered, or extend the array to check more than one.
